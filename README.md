# 🦄 Пинки Пай Бот для MAX

Весёлый и дружелюбный бот для мессенджера MAX, созданный по образу Пинки Пай из мультсериала "Дружба — это чудо". Бот использует российские нейросети GigaChat и YandexGPT для общения.

## ✨ Возможности

*   🎉 Общается в характере Пинки Пай: весело, энергично и дружелюбно.
*   🧁 Делится рецептами выпечки с сайта andychef.ru (один раз в день).
*   🎶 Рассказывает шутки и поет песенки.
*   🌦️ Меняет настроение в зависимости от погоды (грустит, когда идет дождь).
*   📝 С вероятностью 20% комментирует сообщения и картинки.
*   ⏰ Работает с 9:00 до 20:00 ежедневно.

## 🛠️ Технологии

*   **Язык:** Python 3.10+
*   **Библиотека для MAX:** [umaxbot](https://pypi.org/project/umaxbot/) (синтаксис как у aiogram) [citation:4]
*   **ИИ-провайдеры:** GigaChat, YandexGPT.
*   **Парсинг:** BeautifulSoup4, requests.
*   **Деплой:** SprintBox.
