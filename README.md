# 🦄 Пинки Пай Бот для MAX

Весёлый и дружелюбный бот для мессенджера MAX, созданный по образу Пинки Пай из мультсериала "Дружба — это чудо".

## 👨‍💻 Автор

**MADAO81** — разработка и поддержка проекта.

## ✨ Возможности

*   🎉 Общается в характере Пинки Пай
*   🧁 Делится рецептами выпечки
*   🎶 Рассказывает шутки и поет песенки
*   🌦️ Меняет настроение в зависимости от погоды
*   📝 Комментирует сообщения с вероятностью 20%
*   ⏰ Работает с 9:00 до 20:00 ежедневно
