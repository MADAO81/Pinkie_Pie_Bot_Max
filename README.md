# 🦄 Пинки Пай Бот

Весёлый и дружелюбный бот, созданный по образу Пинки Пай из мультсериала "Дружба — это чудо".

> **Статус проекта:** ⏸️ **Разработка приостановлена**
> 
> Проект изначально разрабатывался для мессенджера **MAX** с использованием российских ИИ-сервисов (GigaChat, YandexGPT).
> 
> **Причина паузы:** На данный момент создание ботов в MAX доступно только для юридических лиц, ИП и самозанятых (резидентов РФ). Физические лица не могут пройти верификацию на платформе.
> 
> **Планы:** Работа над проектом будет продолжена, как только появится официальная возможность для физических лиц, либо будет принято решение о переносе на другую платформу (например, Telegram).
> 
> 👨‍💻 *Автор: MADAO81*

## 📖 О проекте

Пинки Пай — это интерактивный бот, который:
- 🎉 Общается в характере персонажа: весело, энергично и дружелюбно
- 🧁 Делится рецептами выпечки с сайта andychef.ru
- 🎶 Рассказывает шутки и поет песенки
- 🌦️ Меняет настроение в зависимости от погоды
- 📝 Комментирует сообщения с вероятностью 20%
- ⏰ Работает в установленные часы

## 🛠️ Технологии

| Компонент | Технология |
|-----------|------------|
| Мессенджер | MAX (в разработке) |
| ИИ-провайдеры | GigaChat (Сбер), YandexGPT (Яндекс) |

| Рецепты | Парсинг andychef.ru |
| Язык | Python 3.10+ |
| Деплой | SprintBox (планируется) |

---

## ⚠️ Важное ограничение

Подключение к платформе MAX для партнёров и её сервисам (чат-ботам, мини-приложениям, каналам) доступно **только для юридических лиц, ИП и самозанятых, которые являются резидентами РФ**.

**Физические лица и нерезиденты пока не могут пройти верификацию** на платформе.

> Официальная позиция MAX: это временная мера, и в будущем планируется запуск новой платформы для разработчиков, которая может открыть доступ и для физических лиц.

## 🚀 Быстрый старт (для разработки)

### 1. Клонируйте репозиторий
```bash
git clone https://github.com/your-username/pinkie-pie-bot.git
cd pinkie-pie-bot
2. Создайте виртуальное окружение
bash
python -m venv venv
source venv/bin/activate  # для Linux/Mac
# или
venv\Scripts\activate     # для Windows
3. Установите зависимости
bash
pip install -r requirements.txt
4. Настройте переменные окружения
Скопируйте файл .env.example в .env и заполните своими ключами:

env
# Для MAX (пока недоступно для физ.лиц)
MAX_BOT_TOKEN=ваш_токен_бота_в_max

# Для GigaChat (Сбер)
GIGACHAT_CREDENTIALS=ваш_ключ_gigachat
GIGACHAT_SCOPE=GIGACHAT_API_PERS

# Для YandexGPT (Яндекс)
YANDEXGPT_API_KEY=ваш_api_ключ_yandexgpt
YANDEXGPT_FOLDER_ID=ваш_folder_id

# Для погоды (Open-Meteo — бесплатно, ключ не нужен)
# WEATHER_API_KEY не требуется!

# Для Яндекс Погоды (опционально, если захотите заменить Open-Meteo)
# YANDEX_WEATHER_API_KEY=ваш_ключ
5. Запустите бота локально
bash
python -m bot.main
